# Delivery Stage 1A — fixture board, columns, and cards

## Real

- Horizontally scrolling, non-wrapping board structure at the approved desktop profile.
- Labeled section regions, loaded-card counts, explicit empty columns, and zero-section board state.
- Compact native-button task cards with factual operation/phase or **No active operation** text.
- All seven approved attention labels and accessible card names.
- Explicit **Load more** control with fixture continuation and polite added-card announcement.
- Unit and browser-level evidence plus representative board screenshots.

## Fixture-backed

- Every section, card, status, attention fact, route identity, and continuation is an explicit local
  design fixture marked non-canonical.
- Load more changes local fixture state only.

## Intentionally absent

- Fresh detail retrieval, task panel, banners, lifecycle shells, routing/history, refresh, and real API
  calls.
- Authentication, canonical PostgreSQL reads, or any mutation authority.

## Known limitations

- Card selection is deliberately inert until Delivery Stage 1B supplies the side panel.
- Final keyboard horizontal-navigation refinements are reserved for Delivery Stage 1D.
